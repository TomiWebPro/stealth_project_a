# Security Model

- Least privilege; permission-based extensions.
- Controlled tool execution via backend services.
- No unrestricted native code by default extensions.
- Secure credential storage per backend.
- Clear active workspace identity.
- AuthZ for projects/members.
- Extension signing/verification/revocation.
- Sandboxed/isolated execution for untrusted extensions.
- Native extensions privileged.
- Filesystem boundaries in desktop client.
- Idempotent job cancellation/retry.
- Data isolation between projects/users/studios.
