# Extension Architecture

Core app + optional extensions: capabilities, UI, provider connectors, local runtimes.

Manifest includes ID, name, version, publisher, type, supported app versions, permissions, capabilities, provider/runtime requirements, UI contributions, dependencies.

Security: permission-based, signing/verification, compatibility, sandboxed/isolated execution, native extensions privileged, safe install/remove/update.

Discovery: official, third-party, private studio registries, manual packages, org-managed.
