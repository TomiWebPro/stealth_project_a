# Development Roadmap

Phase 0 — Foundation (current): discovery, requirements, architecture, contracts, agent workflow, dev env, CI.
Phase 1 — Desktop shell: Tauri app, React frontend, navigation, design system, project/chat interfaces, backend connection config, mock API.
Phase 2 — Core services: auth, projects, conversations, asset metadata, API integration, real-time, job state.
Phase 3 — Asset management: library, details, upload/registration, previews, metadata, relationships, versions, search/filter.
Phase 4 — First production capability: end-to-end image generation with lineage.
Phase 5 — Extension platform: manifest, SDK, registration, install/remove, permissions, connectors, registry.
Phase 6 — Professional capabilities: workspaces, multiple providers, local runtimes, studio integrations, collaboration, advanced lineage.
